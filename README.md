# 🚀 StartupHub — Global Startup Ecosystem & Pitch Deck Matching Platform

An integrated end-to-end ecosystem platform connecting international startups, investors, talent, and automated AI growth agents.

---

## ✨ Key Features

### 1. 🃏 AI Dealflow Swiper & 7-Slide Pitch Deck Studio
* **Gesture-Based Card Swiping**: Swipe Right to match, Left to pass, and Up for Super-Like with native physics and stamp overlays.
* **7-Slide Pitch Deck Studio**: Interactive presentation modal with Problem, Solution & Architecture Moat, Market Size (TAM/SAM/SOM), Unit Economics, Cap Table, and Funding Milestones.
* **Founder 60-Sec Elevator Pitch**: Audio waveform visualizer with synchronized teleprompter transcript.
* **Autonomous AI Diligence Scorecard**: Defensibility score, investment thesis, key risk factors, and comparable valuation multiples.
* **Term Sheet Builder**: One-click SAFE / Convertible Note generator with customizable valuation caps and PDF export.
* **Sound Effects Engine**: High-fidelity Web Audio API tones with audio toggle.
* **Dual View Mode**: Seamless toggle between Tinder-style Swiper and Kanban Pipeline Grid.

### 2. 📹 1-on-1 WebRTC Pitch Room
* Peer-to-peer encrypted real-time video pitch calls.
* Screen-sharing for live pitch deck walkthroughs.
* Real-time text chat and pitch timer telemetry.

### 3. 💼 Talent Marketplace & ATS Optimizer
* Integrated talent directory for engineers, product leads, and growth marketers.
* Autonomous ATS resume analyzer and single-column PDF exporter.

### 4. 📈 Startup Tracker & Marketing Agent
* Live metrics telemetry (ARR, MRR, Burn, Runway).
* AI Autonomous Marketing Team generator for omnichannel campaigns.

### 5. 🛡️ Admin Governance Console
* Password-gated super-admin dashboard with live H2 database statistics and entity management.

---

## 🛠️ Tech Stack

* **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, jsPDF, Web Audio API
* **Backend**: Spring Boot 3.2.3, Java 17, Spring Data JPA, Spring AI, WebSocket (STOMP), Hibernate
* **Database**: Persistent H2 Disk Engine in PostgreSQL compatibility mode

---

## 🏃 Quick Start

### 1. Backend Engine
```bash
cd backend
mvnw spring-boot:run
```
*API running on `http://localhost:8080`*

### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev
```
*UI running on `http://localhost:3000`*
